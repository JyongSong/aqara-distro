1

시작하기 전에

1.1 시스템 개요

Aqara Distro는 본사 ↔ 총판 ↔ 소매점 3단계로 이어지는 발주·거래 흐름을 온라인으로 관리하는 플랫폼입니다. 소매점은 담당 총판에 발주를 요청하고, 총판이 승인하면 본사 또는 총판이 상품을 출고합니다. 소매점은 상품을 받은 뒤 수령 확인을 하고 거래명세서를 출력할 수 있습니다.

1.2 이용 준비물

준비물내용
이메일 주소로그인 ID로 사용됩니다. 담당자가 상시 확인 가능한 주소를 사용하세요.
총판 코드영업 담당자에게서 발급받은 코드입니다. 가입 시 반드시 정확히 입력해야 합니다.
납품 받는 주소상품을 실제로 받는 주소입니다. 우편번호 검색으로 입력합니다.
휴대전화 번호발주 진행 상황이 문자(SMS)/카카오톡으로 안내됩니다.
브라우저PC·모바일 모두 사용할 수 있습니다. 거래명세서 인쇄를 위해 팝업 차단 해제가 필요합니다.

1.3 용어 정리

용어뜻
MOQ최소발주수량. 이 수량보다 적게 주문할 수 없습니다.
발주 단위주문 수량의 배수 단위입니다. 단위가 10이면 10, 20, 30… 형태로만 주문됩니다.
소비자가공식 몰에 표시되는 소비자 판매가격입니다. 소매점 매입 단가와는 다릅니다.
공급가액부가세를 제외한 금액입니다.
부가세 (10%)공급가액의 10%입니다.
송장번호택배 운송장 번호입니다. 출고 시 문자와 주문 상세에서 확인할 수 있습니다.
거래명세서거래 내역을 정리한 인쇄용 문서입니다. 수령 확인 이후 출력할 수 있습니다.

회원가입 및 로그인

2.1 회원가입

회원가입 화면에서 아래 항목을 입력합니다. 별표(*)가 붙은 항목은 필수입니다.

입력 항목필수입력 방법
업체명필수사업장 이름을 입력합니다.
담당자 이름필수실제 담당자 성함을 입력합니다.
연락처필수휴대전화 번호를 입력합니다. 발주 안내 문자를 받는 번호입니다.
이메일 (로그인 ID)필수로그인할 때 사용할 이메일 주소입니다.
납품 받는 주소필수우편번호 조회 버튼으로 검색합니다. 상세 주소만 직접 입력합니다.
총판 코드선택담당 총판에서 받은 코드를 입력합니다. 아래 주의사항을 꼭 확인하세요.

  • 주소 검색 — 팝업 창에서 도로명 주소나 건물명을 검색해 선택합니다.

⚠️
주의 · 총판 코드

총판 코드를 잘못 입력하거나 비워 두면 오류 없이 그대로 가입이 완료되지만, 담당 총판이 배정되지 않아 발주 요청 화면을 사용할 수 없습니다.

  • 코드를 모르거나 확실하지 않으면 가입 전에 영업 담당자에게 먼저 확인하세요.
  • 이미 가입한 뒤 총판이 배정되지 않았다면 영업 담당자에게 총판 배정을 요청해야 합니다.

총판·본사에서 전용 가입 링크를 문자로 받은 경우, 그 링크로 접속하면 신청 시 제출한 정보가 자동으로 채워집니다.

구분항목
자동 입력 (수정 불가)업체명 · 담당자 이름 · 연락처 · 우편번호 · 도로명 주소 · 상세 주소
직접 입력이메일 (로그인 ID) · 총판 코드 (선택) · 비밀번호 · 비밀번호 확인
⚠️
주의 · 링크는 1회용

전용 가입 링크는 한 번만 사용할 수 있습니다. 이미 가입을 마친 링크로 다시 접속하면 「유효하지 않거나 이미 가입 완료된 전용 가입 링크입니다.」 라는 안내가 표시되고 가입하기 버튼이 비활성화됩니다. 이 경우 링크를 발송한 담당자에게 문의하세요.

가입이 완료되면 로그인 화면으로 이동하며 「가입이 완료되었습니다. 로그인하세요.」 안내가 표시됩니다. 가입한 이메일과 비밀번호로 로그인합니다.

화면 안내원인과 조치

계정이 정지되었습니다. 본사에 문의하세요.계정이 정지된 상태입니다. 본사에 문의해야 합니다.

화면 둘러보기

로그인하면 왼쪽에 메뉴가 표시됩니다. 소매점 계정에서 사용할 수 있는 메뉴는 5개입니다.

메뉴주요 기능
📊 대시보드발주 건수 요약과 최근 발주 내역 확인
📦 상품 리스트취급 상품 목록과 소비자가 조회, 상품별 바로 발주
📋 발주 관리발주 현황 조회, 상태별 확인, 주문 상세 진입
🚀 발주 요청상품·수량을 선택해 총판에 발주 요청
⚙️ 계정 설정비밀번호 변경, 로그인 기록 확인

3.2 로그아웃

사이드바 맨 아래의 🚪 로그아웃을 누르면 로그인 화면으로 돌아갑니다. 공용 PC를 사용했다면 반드시 로그아웃하세요.

4

대시보드

로그인 후 처음 보이는 화면입니다. 현재 발주 상황을 한눈에 확인할 수 있습니다.

4.1 통계 카드

카드집계 기준
전체 발주지금까지 요청한 전체 발주 건수
진행 중발주 요청 · 승인완료 · 본사접수 · 출고준비 상태인 건수
출고 완료출고완료 · 수령완료 · 완료 상태인 건수
💡
알아두세요

세 카드의 숫자를 더해도 「전체 발주」와 맞지 않을 수 있습니다. 반려 상태는 「진행 중」과 「출고 완료」 어느 쪽에도 포함되지 않기 때문이며, 정상 동작입니다. 전체 내역은 발주 관리 메뉴에서 확인하세요.

4.2 최근 발주 내역

화면 아래쪽에 최근 5건이 최신순으로 표시됩니다. 주문번호를 클릭하면 해당 주문 상세로 이동하고, 전체 보기를 누르면 발주 관리 화면으로 이동합니다. 발주 내역이 없으면 「아직 발주 내역이 없습니다.」 라고 표시됩니다.

💡
알아두세요

금액이 0원으로 표시되는 것은 총판이 아직 승인하지 않아 단가가 확정되지 않았기 때문입니다. 표시되는 금액은 부가세가 포함되지 않은 공급가액 기준입니다.

5

상품 리스트 확인

현재 취급 중인 전체 상품을 확인할 수 있습니다. 카테고리, 상품명 순으로 정렬되어 있습니다.

5.1 화면 구성

항목설명
이미지상품 사진입니다. 등록된 이미지가 없으면 「없음」으로 표시됩니다.
상품명상품 상세 페이지가 등록된 상품은 파란색 링크로 표시되며, 클릭하면 새 창에서 열립니다.
카테고리상품 분류입니다. 지정되지 않은 상품은 「-」로 표시됩니다.
소비자가소비자 판매가격입니다. 등록되지 않은 상품은 「-」로 표시됩니다.
발주 요청클릭하면 해당 상품이 선택된 상태로 발주 요청 화면이 열립니다.
💡
알아두세요

상품 리스트에는 소비자가만 표시됩니다. 소매점 매입 단가는 총판이 발주를 승인한 뒤 해당 주문 상세 화면에서만 확인할 수 있습니다.

상품 리스트에는 검색창이나 카테고리 필터가 없습니다. 브라우저의 페이지 내 찾기(Ctrl+F / ⌘+F)를 이용하면 편리합니다.

5.2 상품 목록에서 바로 발주하기

상품 행의 발주 요청 버튼을 누르면 그 상품이 이미 선택된 상태로 발주 요청 화면이 열립니다. 수량만 조정한 뒤 진행하면 됩니다.

6

발주 요청하기

★ 이 매뉴얼의 핵심

소매점이 총판에 상품을 주문하는 화면입니다. 아래 6단계를 순서대로 따라 하세요.

1발주 요청 화면 열기

두 가지 경로가 있습니다.

  • 사이드바 — 🚀 발주 요청 메뉴를 클릭합니다.
  • 상품 리스트 — 원하는 상품 행의 발주 요청 버튼을 클릭합니다. 해당 상품이 자동 선택됩니다.
2상품·옵션·수량 선택
  • 상품 선택 — 목록에서 주문할 상품을 고릅니다.
  • 옵션 선택 — 옵션이 있는 상품은 옵션 항목이 함께 표시됩니다. 옵션이 없는 상품은 이 항목이 나타나지 않습니다.
  • 수량 입력 — − / + 버튼이나 숫자 입력으로 조정합니다. 상품을 고르면 최소 수량(MOQ)이 자동으로 채워집니다.
  • 추가 클릭 — 아래 「발주 품목」 목록에 담깁니다. 추가 후 상품·옵션 선택은 초기화됩니다.
💡
수량이 저절로 바뀌어요

입력한 수량이 저절로 바뀌는 것은 정상입니다. 시스템이 최소 수량(MOQ)과 발주 단위에 맞춰 자동으로 보정하기 때문입니다.

예를 들어 MOQ가 10, 발주 단위가 5인 상품에 7을 입력하면 10으로, 12를 입력하면 10으로, 13을 입력하면 15로 조정됩니다. MOQ와 발주 단위는 상품마다 다르며, 상품을 고르면 수량 옆에 「MOQ : 단위」 형태로 표시됩니다.

3품목 확인 및 삭제

추가한 품목은 「발주 품목」 표에 상품명과 수량으로 표시됩니다. 옵션이 있으면 상품명 뒤에 괄호로 함께 표시됩니다. 잘못 담은 품목은 오른쪽 삭제를 눌러 뺄 수 있습니다.

⚠️
주의

삭제를 누르면 확인 창 없이 바로 지워집니다.

이 화면에는 가격이 표시되지 않습니다. 단가와 금액은 총판이 승인한 뒤 주문 상세에서 확인할 수 있습니다.

4배송 정보 입력
항목필수설명
배송지선택가입 시 등록한 주소가 자동으로 입력됩니다. 다른 곳으로 받으려면 직접 수정합니다.
희망 납기일선택원하는 납품 날짜가 있으면 선택합니다.
비고선택총판에 전달할 요청사항을 입력합니다.
5발주 요청 제출

모든 입력을 마쳤으면 화면 아래 발주 요청하기 버튼을 누릅니다. 제출되면 발주 관리 목록으로 이동하며, 담당 총판에게 새 발주 요청 문자가 자동 발송됩니다.

⚠️
주의

취소를 누르면 작성 중이던 내용은 저장되지 않고 이전 화면으로 돌아갑니다. 이 화면에는 임시 저장 기능이 없습니다.

제출한 발주는 소매점이 직접 취소하거나 수정할 수 없습니다. 잘못 제출했다면 담당 총판에 연락해 반려를 요청하세요.

6발주 요청이 막혀 있을 때

아래 두 경우에는 상품 선택 화면이 아예 표시되지 않습니다.

화면 안내원인과 조치
총판이 배정되지 않았습니다.가입 시 총판 코드를 입력하지 않았거나 잘못 입력한 경우입니다. 본사에 연락해 총판 배정을 요청하세요.
주문이 제한된 상태입니다.계정이 주문 제한 상태입니다. 담당 총판 또는 본사에 문의하세요.
7

수령 확인과 거래명세서

1출고 안내 확인

상품이 출고되면 등록된 연락처로 출고 안내 문자가 발송됩니다. 문자에는 송장번호와 택배사가 함께 안내되며, 주문 상세 화면에서도 같은 내용을 확인할 수 있습니다.

2수령 확인 누르기

상품을 실제로 받은 뒤, 주문 상세 화면 아래의 수령 확인 버튼을 누릅니다. 주문 상태가 수령완료로 바뀝니다.

⚠️
주의

수령 확인은 확인 창 없이 누르는 즉시 처리되며, 소매점이 되돌릴 수 없습니다. 상품과 수량을 모두 확인한 뒤에 누르세요. 문제가 있으면 누르기 전에 담당 총판에 먼저 연락하세요.

3거래명세서 인쇄

수령 확인이 끝나면 주문 상세 아래에 거래명세서 인쇄 버튼이 나타납니다. 버튼을 누르면 새 창이 열리고 인쇄 화면이 자동으로 실행됩니다.

거래명세서에는 주문번호, 발주일, 배송지와 함께 품목별 상품 · 옵션 · 수량 · 단가 · 금액이 표시되고, 아래에 공급가액 · 부가세 (10%) · 합계와 한글 금액이 인쇄됩니다.

⚠️
주의 · 팝업 차단

브라우저가 팝업을 차단하면 인쇄 창이 열리지 않습니다. 주소창 오른쪽의 팝업 차단 안내를 눌러 이 사이트의 팝업을 허용한 뒤 다시 시도하세요.
